# Dubowl Bêta

**Dubowl** est un logiciel de bande rythmo pour le doublage. Cette page ne sert qu'à télécharger la **version bêta**.

## Télécharger

Va dans **Releases** (à droite de cette page) puis choisis ton fichier :

- **Mac** : `Dubowl-Beta-mac.zip` (décompresse-le, puis clic droit sur l'application › **Ouvrir** au premier lancement).
- **Windows** : `Dubowl-Beta.exe` (installateur ; Windows peut afficher un avertissement « SmartScreen » : *Informations complémentaires* › *Exécuter quand même*).

## Licence de bêta

La bêta demande une licence personnelle. Au premier lancement, Dubowl affiche l'identifiant de ton ordinateur : envoie-le à la personne qui t'a invité, tu recevras un fichier `licence.json` à importer avec le bouton « Importer ma licence… ».

La bêta est confidentielle : merci de ne pas partager le programme.
